SACS-Amazônia

Alerta de calor e saúde na Amazônia Legal: previsão de ondas de calor, perfil dos municípios e a relação entre calor e saúde.

Ferramenta em desenvolvimento. Ainda não validada para decisões operacionais.

Abrir o painel

O painel roda no computador do desenvolvedor. O botão abre a versão pública nesse computador:

Abrir o painel (http://127.0.0.1:8001)

Esse endereço só funciona no computador onde o painel está rodando. Em outros computadores, o painel ainda não tem endereço público fixo.

Como rodar localmente

A partir do repositório do projeto:

SACS_MODO=publico PAINEL_DADOS=dados_publico uv run shiny run app.py --port 8001
